# OmniSQL fork review

All 35 forks returned by the upstream fork listing, plus the nested A-viral-dev fork under PXSR, were enumerated. All 69 public branches were compared with upstream `main` at `94165f5`. Seventeen forks have at least one branch with commits outside that history; this includes older implementations and repeated copies of one refactor, so it does not mean seventeen new features.

## Useful changes

| Fork | Change to consider | Treatment |
| --- | --- | --- |
| [Etsuya233](https://github.com/Etsuya233/omnisql-mcp/tree/feat/hierarchical-resources) | Hierarchical resources and schema-aware metadata | Adapt connection summaries and lazy catalog reads; apply the shared access policy |
| [PescaDev](https://github.com/PescaDev/dbeaver-mcp-server) | Spaces and Unicode in connection names, SSL handler properties, connection-level resource listing | Replace lossy identifier sanitization and keep raw credentials private |
| [pavelpp-topia](https://github.com/pavelpp-topia/omnisql-mcp) | Explicit SQL Server encryption and certificate settings | Share TLS resolution between normal queries and pools |
| [mason-respark](https://github.com/mason-respark/omnisql-mcp) | Native ClickHouse, bounded-directory file exports, structured expired-auth results, SSO login, older environment aliases | Port useful behavior into the current adapters; strengthen file creation and result budgets; keep login an explicit user action |
| [bemyak](https://github.com/bemyak/omnisql-mcp) | ProxyJump, keepalive settings, and additional SSH property spellings | Add multi-hop support after tunnel lifecycle and host-key checks are tested |
| [A-viral-dev](https://github.com/A-viral-dev/dbeaver-mcp-server) | Engine-level read-only enforcement and DuckDB or Quack connections | Adapt read-only execution and DuckDB; require configured targets rather than automatic fallback endpoints |
| [simonegiacomelli](https://github.com/simonegiacomelli/dbeaver-mcp-server) | Disable GUI CLI fallback and add a read-only guard | Reject fallback paths that cannot enforce policy; do not replace the guard with the fork's simpler regex |
| [nick-titus](https://github.com/nick-titus/dbeaver-mcp-server) | SQL Server cleanup and RDS connection handling | Retain cleanup and TLS lessons in the shared lifecycle code |

Older MySQL, Azure SQL, SSL, and configuration work in eliranmoyal, kiprasmel, siegelpeter, and fzvincent overlaps current support. Recheck the remaining behavior rather than importing entire historical implementations. The shared `b2cc1218` refactor appears in several forks; it is one old architectural change, not several features. iflow-mcp changes packaging, and ndrini contains an installation draft and a machine-specific Gemini example.

Macioa adds credential-listing and password-setting tools and tracks an environment file. Do not import credential-disclosure tools or copy its environment file. The public commit metadata was enough to identify that behavior; no credential values are included here.
